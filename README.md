# ATM-Pal
This repository contains our codebase for ATM-Pal, which is an integrated QR scanner for an ATM utilizing NCR's API calls. ATM-Pal is our submission for the 2021 UGAHacks 6 hackathon.

# About ATM-Pal
ATM-Pal is a hackathon project whose purpose is to streamline the ATM transaction process and minimize the spread of COVID-19 by reducing contact payment.

# Awards
- 1st prize in Capital One Best Financial Hack
- 3rd prize in NCR Corporation Challenge
